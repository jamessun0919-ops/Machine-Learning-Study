多元線性回歸

Multiple Linear Regression · 監督式學習－迴歸
①

簡介

多元線性回歸是簡單線性回歸的延伸，用兩個以上自變數（特徵）來預測一個連續的目標變數。例如：用新創公司的「研發、行政、行銷」三項支出，預測其「獲利」。假設目標變數與各特徵之間存在線性關係，只是這條「線」變成了高維度的「平面」或「超平面」。
監督式學習 迴歸任務 最小平方法（常態方程式）
②

模型公式

y  =  β₀ + β₁x₁ + β₂x₂ + ⋯ + βₙxₙ + ε
β̂  =  (Xᵀ X)⁻¹ Xᵀ y
β₀ 是截距、β₁…βₙ 是各特徵的係數、ε 是誤差項。訓練目標是找到一組 β̂ 使殘差平方和（RSS）最小——上面第二條公式就是這個最佳化問題的代數閉式解，稱為常態方程式（Normal Equation）。
③

適用情境與假設限制

✓ 適合使用的情境

  • 目標變數與特徵之間大致呈線性關係
  • 需要模型「可解釋」——每個係數直接告訴你該特徵每增加一單位對目標值的影響

⚠ 假設與限制

  • 線性關係假設：明顯非線性時應考慮 Polynomial Regression
  • 殘差獨立同分布：違反時標準誤與信賴區間會不準確
  • 多重共線性：特徵間高度相關時，係數估計會變得不穩定
④

評估指標

R²（決定係數）

R²  =  1 − Σ(yᵢ − ŷᵢ)² Σ(yᵢ − ȳ)²

範圍 0～1，越接近 1 代表模型解釋力越強。

RMSE（均方根誤差）

RMSE  =  √( mean( (yᵢ−ŷᵢ)² ) )

單位與目標變數相同，數值越小代表預測越準。

⑤

常見誤區

  • 把相關性當因果——R&D 支出與獲利高度相關，不代表「花更多錢在研發上」必然「因果上」導致獲利提高，可能兩者都受第三個因素（如公司規模）影響。
  • 忽略多重共線性——看到某特徵的係數很小，就直接判斷「這個特徵不重要」，但如果它跟另一個特徵高度相關，係數的大小可能只是反映了共線性，而非真實的影響力。
  • 外插（Extrapolation）——模型只在訓練資料的數值範圍內可靠，超出範圍的預測不保證線性關係依然成立。
