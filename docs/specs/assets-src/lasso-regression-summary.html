Lasso 迴歸

Lasso Regression · 監督式學習－迴歸
①

簡介

Lasso Regression 在線性回歸的損失函數中加入 L1 正則化項（係數絕對值之和）。與 Ridge 不同，L1 懲罰會把不重要的係數直接壓成恰好 0，等於在訓練模型的同時自動做「特徵選擇」。
監督式學習 迴歸任務 L1 正則化
②

模型公式

J(β)  =  Σ(yᵢ − ŷᵢ)² + λΣ|βⱼ|
βⱼ  ←  S(ρⱼ, λ/2) / Σxᵢⱼ²
懲罰項不包含截距 β₀。L1 項在 βⱼ=0 處不可微分，沒有閉式解，需用 coordinate descent 迭代求解——這是與 Ridge 最根本的差異。
③

適用情境與假設限制

✓ 適合使用的情境

  • 想自動做特徵選擇、精簡模型
  • 特徵數多，懷疑許多是雜訊或冗餘
  • 需要可解釋性較高、係數較稀疏的模型

⚠ 假設與限制

  • 沒有閉式解，計算成本較 Ridge 高
  • 特徵高度相關時，特徵選擇結果不穩定
  • 前提是特徵已標準化，否則懲罰力道不公平
④

評估指標

RMSE（均方根誤差）

RMSE  =  √( mean( (yᵢ−ŷᵢ)² ) )

train/test 雙集顯示，可看出正則化對泛化能力的影響。

歸零係數數量

count( |βⱼ| = 0 )

Lasso 特有指標，量化特徵選擇的效果——數量越多，代表模型認為越多特徵是冗餘的。

⑤

常見誤區

  • 誤以為 Lasso 和 Ridge 效果差不多——可微性差異直接導致行為質變（歸零 vs 平滑收縮）。
  • 誤以為選出的特徵組合就是「真正重要」的特徵——特徵高度相關時，被選中或歸零可能是任意的。
  • 忘記標準化就直接套用 Lasso——懲罰力道會被特徵尺度扭曲。

  • 同樣 λ=0.01，Ridge 平滑收縮全部 15 個係數，Lasso 卻讓其中 7 個係數恰好歸零——L1 懲罰項不可微分的數學性質，直接導致這個行為質變。

  • 兩者都是正則化工具，但解決的問題不同：Ridge 適合「保留所有特徵、只是要抑制係數過大」，Lasso 適合「想自動篩掉不重要的特徵」。
