多項式回歸

Polynomial Regression · 監督式學習－迴歸
①

簡介

多項式回歸是線性回歸的延伸：把特徵轉換為 $x, x^2, \ldots, x^d$ 等高次項，讓模型能配適曲線關係而非僅限直線。雖然預測值是 $x$ 的非線性函數，但對係數 $\beta$ 而言仍是線性組合，因此仍能用最小平方法求解。
監督式學習 迴歸任務 多項式特徵＋常態方程式
②

模型公式

y  =  β₀ + β₁x + β₂x² + ⋯ + βdxᵈ + ε
β̂  =  (Xᵀ X)⁻¹ Xᵀ y
對 $x$ 而言是非線性曲線，但對係數 $\beta_0 \ldots \beta_d$ 而言仍是線性組合——所以能直接沿用多元線性回歸的常態方程式求解，把 $x^2 \ldots x^d$ 當成新特徵欄位即可。
③

適用情境與假設限制

✓ 適合使用的情境

  • 特徵與目標在散布圖上呈現明顯曲線（非直線）趨勢
  • 仍需要一定可解釋性，但關係不是簡單線性

⚠ 假設與限制

  • 次數選擇＝bias-variance 權衡：太低欠擬合、太高過擬合
  • 外插風險比線性回歸更嚴重，訓練範圍外會劇烈發散
  • 本質仍是線性模型的特例，只是特徵做了非線性轉換
④

評估指標

R²（決定係數）

R²  =  1 − Σ(yᵢ − ŷᵢ)² Σ(yᵢ − ȳ)²

範圍 0～1，越接近 1 代表模型解釋力越強。

RMSE（均方根誤差）

RMSE  =  √( mean( (yᵢ−ŷᵢ)² ) )

單位與目標變數相同，數值越小代表預測越準。

⑤

常見誤區

  • 只看訓練集 R² 判斷次數好壞——次數越高，訓練集 R² 幾乎必然越高，但不代表模型真的更好。
  • 把多項式回歸和非線性模型混為一談——它對係數而言仍是線性模型，與決策樹、神經網路等真正的非線性模型不同。
  • 忽略外插風險——高次多項式曲線在訓練範圍外可能劇烈偏離合理範圍，不能拿模型預測範圍外的職等。
