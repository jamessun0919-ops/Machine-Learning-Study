簡介

不同特徵的數值尺度差異，會讓某些機器學習演算法產生偏差判斷。特徵工程（Feature Engineering）泛指所有讓原始資料更適合模型學習的前處理技巧，本站聚焦其中最基礎、最常用的兩類：數值特徵的標準化/縮放，以及類別特徵的編碼。

縮放方法

Z-score 標準化

z  =  x − μσ

平均值為 0、標準差為 1，仍保留離群值的相對位置。

Min-Max 縮放

x'  =  x − minmax − min

固定落在 [0, 1] 範圍，但對離群值敏感。

③

適用情境

✓ 需要標準化的模型

  • 以「距離」為核心運算：KNN、SVM、K-Means
  • 以「梯度」為核心運算：梯度下降訓練的迴歸/邏輯斯迴歸、神經網路

○ 不需要標準化的模型

  • 樹狀模型：Decision Tree、Random Forest、Boosting
  • 以「切分點」而非距離運算，特徵尺度不影響判斷
④

常見誤區

  • 用整個資料集一起計算標準化參數——正確做法是只用訓練集算出縮放參數再套用到測試集，否則會造成 Data Leakage、評估結果過度樂觀。
  • 對無序類別使用 Label Encoding——模型會誤讀類別間的大小/距離關係。
  • 忘記標準化就套用距離型演算法——尺度大的特徵會不成比例主導距離計算，且不會報錯，容易被忽略。
