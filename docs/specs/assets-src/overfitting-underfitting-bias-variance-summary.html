簡介

過擬合指模型過度學習了訓練資料中的雜訊，導致在訓練集上表現極佳卻無法類推到新資料；欠擬合則相反，模型過於簡單，連訓練資料本身的規律都學不好。兩者的核心都是模型複雜度與泛化能力之間的取捨。

③

適用情境與限制

✓ 適用範圍

  • 任何監督式學習模型（迴歸/分類皆然）
  • 貫穿後續所有演算法章節的共通概念

○ 限制

  • 真實 Bias/Variance 無法直接測量，只能間接估計
  • 不同模型的「複雜度旋鈕」不同，需個別章節說明
④

常見誤區

  • 只看訓練誤差判斷模型好壞——訓練誤差趨近於 0 反而可能是過擬合警訊，而非模型優秀的證明。
  • 以為增加複雜度是萬靈丹——複雜度提升到一定程度後，test 誤差會反轉上升。
  • 用 test set 反覆調整模型複雜度——應改用驗證集或交叉驗證來挑選模型複雜度。
