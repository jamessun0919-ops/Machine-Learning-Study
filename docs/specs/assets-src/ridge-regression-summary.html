Ridge 迴歸

Ridge Regression · 監督式學習－迴歸
①

簡介

Ridge Regression 在線性回歸的損失函數中加入 L2 正則化項（係數平方和），透過懲罰過大的係數來抑制過擬合、提升泛化能力。核心概念：用一點點偏差換取更低的變異數。
監督式學習 迴歸任務 L2 正則化
②

模型公式

J(β)  =  Σ(yᵢ − ŷᵢ)² + λΣβⱼ²
β̂  =  (Xᵀ X + λI′)⁻¹ Xᵀ y
懲罰項不包含截距 β₀；λ=0 時退化為普通最小平方法（OLS）。使用前必須先將特徵標準化，否則不同尺度的係數受懲罰程度不一致。
③

適用情境與假設限制

✓ 適合使用的情境

  • 特徵數多、疑似過擬合
  • 特徵間有相關性（多重共線性）
  • 仍想保留所有特徵，只是要抑制係數過大

⚠ 假設與限制

  • λ 需要調整，可用交叉驗證挑選
  • 係數會縮小但不會恰好變成 0，無法做特徵選擇
  • 前提是特徵已標準化，否則懲罰力道不公平
④

評估指標

R²（決定係數）

R²  =  1 − Σ(yᵢ − ŷᵢ)² Σ(yᵢ − ȳ)²

範圍 0～1，越接近 1 代表模型解釋力越強。

RMSE（均方根誤差）

RMSE  =  √( mean( (yᵢ−ŷᵢ)² ) )

train/test 雙集顯示，可看出正則化對泛化能力的影響。

⑤

常見誤區

  • 忘記標準化就直接套用 Ridge——懲罰力道被特徵尺度差異扭曲，係數收縮不公平。
  • 誤以為 λ 越大一定越好——λ 過大會嚴重欠擬合，係數被壓縮到接近 0。
  • 誤以為正則化能把不重要特徵徹底排除——Ridge 只縮小係數，不會將其歸零。

  • λ=0（無正則化）時，次數 15 的係數最大絕對值高達 1450，是典型的係數爆炸案例。
  • 加入 λ=0.01 後，係數最大絕對值降到 5.76（收縮約 252 倍），test RMSE 從 0.8024 降到 0.3204（改善約 60%）。
  • λ 白名單（0, 0.01, 0.1, 1, 10）掃過後，λ=0.01 是本資料集的最佳點；λ 再往上（如 10）test RMSE 反而回升至 1.3658，代表過度正則化導致欠擬合。
