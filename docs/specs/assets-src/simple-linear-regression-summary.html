簡單線性回歸

Simple Linear Regression · 監督式學習－迴歸
①

簡介

簡單線性回歸是機器學習中最基礎、最直觀的迴歸演算法，用單一特徵來預測一個連續的目標變數。例如：只用新創公司的「研發支出」單一投入，預測其「獲利」。幾何上，就是在二維散布圖上找一條最貼合資料點的直線。
監督式學習 迴歸任務 最小平方法閉式解
②

模型公式

y  =  β₀ + β₁x + ε
β̂₁  =  Σ (xᵢ − x̄)(yᵢ − ȳ) Σ (xᵢ − x̄)²
β̂₀  =  ȳ − β̂₁ x̄
β₀ 是截距、β₁ 是斜率、ε 是誤差項。訓練目標是找到一組 β̂₀、β̂₁，使殘差平方和（RSS）最小——上面兩條公式就是對 RSS 求偏導數並令其為 0 之後，推導出的代數閉式解。
③

適用情境與假設限制

✓ 適合使用的情境

  • 散布圖上呈現明顯的線性趨勢
  • 需要極高可解釋性——斜率直接告訴你邊際影響

⚠ 假設與限制

  • 線性假設：非線性關係會產生系統性偏差
  • 易受離群值影響，拉動整條回歸線
  • 單一變數侷限，易欠擬合（Underfitting）
④

評估指標

R²（決定係數）

R²  =  1 − Σ(yᵢ − ŷᵢ)² Σ(yᵢ − ȳ)²

範圍 0～1，越接近 1 代表模型解釋力越強。

RMSE（均方根誤差）

RMSE  =  √( mean( (yᵢ−ŷᵢ)² ) )

單位與目標變數相同，數值越小代表預測越準。

⑤

常見誤區

  • 把相關性當因果性——R&D 支出與獲利高度線性相關，不代表砸更多錢研發就必定同比例提升獲利，可能兩者都受公司規模或市場景氣影響。
  • 忽視離群值——沒有先看散布圖就套公式，少數極端點會讓整條回歸線失真。
  • 外插推論（Extrapolation）——模型只在訓練資料的數值範圍內可靠，超出範圍的預測不保證線性關係依然成立。
